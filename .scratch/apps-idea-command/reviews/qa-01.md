## Exploratory charter

**Charter (30 minutes):** text that is hostile, ambiguous or non-English; resends and retries; parallel senders; the queue across days and holds; and what reaches Discord.

**Findings:**

- **D02 and D03** are above, with tickets and red tests.
- **O1 (low, by design): a URL-first idea gets a URL for a name.** "Https://www.iras.gov.sg/taxes/goods-services-tax-(gst) a GST" fits the 60-character cap, and the factory is told to rename it. A plainer fallback would skip leading URL words. This is not a defect: the PRD says "its first few words".
- **O2 (by spec): plurals and extra words aren't caught as duplicates.** "Quote builders" and "Payslip maker for my staff" get past the exact slug and name checks that the ticket names. The factory's own near-duplicate check still applies at PRD time.
- **O3 (cosmetic): flow-style YAML text gives an odd name.** `{ name: x, …}` is named "{ name", with the slug `name`. Nothing is injected, because the row stays `idea` and `ting-yu`.
- **O4 (cosmetic): accented letters drop out of the slug.** "Café menu maker" becomes `caf-menu-maker`. The slug rule was already on `main`.
- **O5 (low, worth a line to the developer): one run can hold every one of his ideas.** The prompt says "Hold only the first idea in the list; the next one waits for tomorrow's run", but the code allows one hold after another on the same day, each on the new head (H7). PRD §5.6 says only "only the oldest open idea can be held", so this meets the spec. But a hold has no undo (N5, deferred). Capping holds at one a day in `ideas.hold` would make the prompt's rule hold.
- **O6 (low): a resend gets advice that doesn't fit.** When Dispatch retries after a lost answer, or Ting Yu resends an idea that is already in, or that was held (X1), the reply says "clashes with Site visit report (backlog: idea). Send it with a different name before a colon." Following that advice adds the same idea under a second name. The contract does say "Not retry-safe". A reply that says "you sent this idea on <date>", and "it was held: <reason>" when it was, would read better.
- **O7 (info): long queues give long numbers in the reply.** After 36 ideas the reply reads "36 older ideas of yours come first; the app factory writes at most one PRD a day". That is accurate, and it is an interface count.
- **Phone width, back button and two tabs:** not applicable, because there is no UI. The "two tabs" equivalent is parallel senders (C11a–b, the burst and C11c), and it passed.
